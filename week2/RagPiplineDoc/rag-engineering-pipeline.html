QUERY TRANSFORMATION METHODS
  • 1. Rewrite — Fix grammar, spelling, clarity
  • 2. Expand — Add synonyms, related terms
  • 3. Decompose — Break complex query into sub-queries
  • 4. Hypothetical Questions — Generate questions that docs may answer
  • 5. Step-back — Ask higher level question then drill down
  • 6. Multi-query — Generate multiple variations
  • 7. RAG-Fusion Query — Combine multiple transformations + RRF
METADATA FILTERING METHODS
A. Filter Extraction
  • Rule-based (keywords, patterns)
  • LLM-based (structured output)
  • Application / User Context
B. Filter Application
  • 1. Pre-Filtering (Filter → Search) — Faster, more secure, higher precision, may reduce recall
  • 2. Post-Filtering (Search → Filter) — Higher recall, slower, less efficient
C. Common Filters
  • department, country, year, tenant_id, doc_type, author, source, permissions

RRF (FUSION) METHODS
1. Reciprocal Rank Fusion (RRF)

Score(d) = Σ 1 / (k + rank_i(d))   (k = constant, usually 60)

2. Weighted RRF

Assign weights to each retriever

3. CombSUM / CombMNZ

Sum normalized scores

4. Distribution Based Fusion

Use score distributions for fusion

BEST PRACTICES
